# Tech Minimal - Professional Web Development Portfolio

![Tech Minimal Preview](https://via.placeholder.com/1200x630/0a0a0a/00ff9d?text=Tech+Minimal)

## 🚀 Overview

A modern, responsive portfolio website for a professional web development business. Built with Bootstrap 5, custom CSS, and JavaScript.

## ✨ Features

- 🔥 **Modern Design** - Clean, minimal aesthetic with dark/light mode
- 📱 **Fully Responsive** - Works on all devices
- 🎨 **Dark/Light Theme** - User preference saved in localStorage
- ⚡ **Fast Loading** - Optimized with preloader
- 📊 **Animated Counters** - Interactive statistics
- 📝 **Contact Form** - Ready to connect to backend
- 🛠️ **Services Page** - Detailed service offerings
- 📁 **Portfolio Showcase** - Project gallery
- 💬 **Testimonials** - Social proof section
- 🔍 **SEO Ready** - Meta tags and semantic HTML

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Custom variables, animations, responsive
- **Bootstrap 5** - Grid system and components
- **JavaScript** - Interactive features
- **Font Awesome** - Icon library
- **Google Fonts** - Inter font family
